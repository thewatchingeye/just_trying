VOICE LEVEL CALIBRATION
Calibrates the mic so only your voice (not speaker bleed) triggers AI response. The mic auto-enables. AI guides you: (1) stay silent while sample voices play, (2) speak normally when you hear "Go".

Important — use OpenAI TTS for everything:
Browser TTS (Mac voices) bypasses the browser's echo cancellation, so it bleeds into the mic ~25× more than OpenAI TTS. For clean voice recognition, enable BOTH "OpenAI TTS for AI voice" AND "OpenAI TTS for category voices" in the Voices tab.

Tips:
• Set all volume sliders to session values BEFORE calibrating
• Lower Mac mic input gain (System Settings → Sound → Input) — surprisingly often works better
• Use a directional cardioid vocal mic if possible
